# Kaggle соревнование
Цель этого конкурса — разработать рамки машинного обучения, способные выявлять недостаточно изученные виды на основе непрерывных аудиоданных с водно-болотных угодий Пантанал в Бразилии.

Понадобиться активная учетная запись на kaggle И сгенерированный API token

## Скачать датасет
```bash
kaggle competitions download -c birdclef-2026
```

## Разархивировать
```bash
mkdir data
unzip birdclef-2026 -d data/
rm birdclef-2026.zip
```
